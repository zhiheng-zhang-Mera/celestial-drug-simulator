# DEV-09 desktop HTML anatomy

User-selected reference rendering is a native embedded WebEngine child of the existing Tk anatomy panel, not an external browser window. Run the unchanged `python -m src.app` entry. Windows Python with Tk and installed PySide6/QtWebEngine6.12 is required for the HTML view; no runtime packages are installed automatically. Missing runtime, load failure or WebGL failure is shown in the UI. The Simplified View button retains the previous offline BodyParts3D renderer; restart the module to restore HTML.

The original full dashboard/scene is local under assets/web. Source mode defaults to translucent neutral material; five atomoxetine regions alone receive existing source-category highlights. Optional original system colors are explicitly labeled as structural colors, not drug effects. Twenty existing regions are accessible through both embedded and native directory controls, including when HTML cannot load. The duplicate native selector is intentionally retained for degraded-mode accessibility. Existing multi-drug, custom substance, physiology, PGx, export and external Throne mount remain unchanged.

Python owns identities/evidence. HTML receives only region catalog, selected identity-derived evidence, effect categories and display substance name; no physiology/genotype/regimen export is sent to the renderer. Selection returns a whitelisted region ID via Qt WebChannel -> JSON-line stdout -> Tk event queue. Local off-record WebEngine profile and request interception limit loading to assets/web, data images and Qt's WebChannel resource. External navigation/network are blocked in this renderer. Source links remain the existing explicit Python browser action. Drug text is rendered with textContent, never HTML injection.

Native embedding occurs after Qt's initial show events (which can recreate HWNDs), and uses the parent client rectangle plus Qt DPR to fit at150% Windows scaling. Resize updates child bounds; parent visibility governs tab hiding; closed stdin/invalid native parent exits the child. Renderer errors go to module-local ignored data/cache/webview.log. The HTML scene is schematic, including original organ positions; not the prior imported anatomical atlas or a physiological simulator.

Validation: `python -m unittest discover -s tests`; `node --test tests/web_anatomy.test.mjs`. Review found round-trip drag click and fallback selected-layer mismatch; regression tests and fixes included. Startup/media retention limitations are recorded separately; no clinical inference or release approval.
